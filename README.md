## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/createwithbhumi.git
```

### 2. Navigate to the project

```bash
cd createwithbhumi
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
